# Atlas SWE-Explore census

This experiment applies the fixed depth-seven Atlas language to every unique
structurally valid repository snapshot in the frozen 78-case SWE-Explore
JavaScript/TypeScript population.

Read the [preregistered protocol](PREREGISTRATION.md) before the results. The
result will contain typed Parquet observation, physical-work, snapshot, and
case-join tables plus a generated Markdown report.

No issue text, embedding model, Jev call, provider credential, or evaluator
gold is an input. The two Three.js cases censored from localization remain in
scope because their retained repository structure is independent of the
embedding context limit.
